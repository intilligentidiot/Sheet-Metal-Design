# Sheet Metal Bend Allowance Calculator Tool

A modern, responsive, precision engineering tool for calculating **Bend Allowance (BA)**, **Bend Deduction (BD)**, **Outside Setback (OSSB)**, and **ISO 2768-m Tolerances** in real time, featuring dynamic SVG cross-section bend diagrams and downloadable high-resolution PDF engineering reports.

Compliant with **ASME Y14.5** and **ISO 2768-m** standards.

---

```text
bend-calculator-tool/
```

## 🚀 Quick Start (Standalone)

1. Unzip the archive.
2. Double-click `index.html` to open it in any modern browser (Chrome, Edge, Firefox, Safari).
3. The tool runs **100% client-side** in the browser with **no backend server or database required**.

## 🌐 How to Add to a Different Site

### Method 1: Host as its own Page or Subdirectory
Upload the entire folder to your web server (e.g., Apache, Nginx, Vercel, Netlify, cPanel):
- Put files in `https://yourdomain.com/tools/bend-calculator/` or root.
- The `index.html` file will serve as the complete standalone page with header, hero, calculator, and footer.

## ⚙️ Features & Customization

### 1. Material Presets & Default K-Factors
In `bend-calculator.js`, you can adjust or add material presets:
```javascript
const MATERIALS = {
    mild_steel:       { name: 'Mild Steel',       kFactor: 0.44 },
    aluminum:         { name: 'Aluminum',         kFactor: 0.33 },
    stainless_steel:  { name: 'Stainless Steel',  kFactor: 0.45 },
    copper:           { name: 'Copper',           kFactor: 0.38 },
    brass:            { name: 'Brass',            kFactor: 0.35 },
    titanium:         { name: 'Titanium',         kFactor: 0.42 },
    spring_steel:     { name: 'Spring Steel',     kFactor: 0.45 },
    galvanized_steel: { name: 'Galvanized Steel', kFactor: 0.44 },
    custom:           { name: 'Custom',           kFactor: null }
};
```

### 2. Changing Theme & Brand Accent Color
In `bend-calculator.css`:
```css
:root {
    --accent: #cc0000;         /* Replace with your brand color */
    --accent-hover: #990000;
    --accent-glow: rgba(204, 0, 0, 0.25);
}
```
And in `tailwind.config` in `index.html`:
```javascript
primary: '#cc0000' /* Set to your primary color */
```

### 3. PDF Engineering Report Customization
The PDF report generated by the "Print Results" button uses the hidden template `#pdf-template` inside `index.html`. You can customize the report title, company branding, and contact details by editing the template footer section in `index.html`.

## 📜 Engineering Formulas Used

- **Bend Allowance (BA):**
  $$BA = \frac{\pi}{180} \times A \times (R + K \times T)$$

- **Outside Setback (OSSB):**
  $$OSSB = (R + T) \times \tan\left(\frac{A}{2} \times \frac{\pi}{180}\right)$$

- **Bend Deduction (BD):**
  $$BD = 2 \times OSSB - BA$$

Where:
- $A$ = Bend Angle in degrees
- $R$ = Inside Bend Radius
- $T$ = Sheet Metal Thickness
- $K$ = K-Factor (neutral axis location ratio, $0 < K \le 1$)
